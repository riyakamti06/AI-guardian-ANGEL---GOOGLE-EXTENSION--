Get Started with Guardian AI Angel

You can inspect the source code and install the extension in Chrome for development and testing.

  1. Open the GitHub repository.
    Visit the project source code using the button below.
  2. Download the project.
    Click the green Code button, then choose Download ZIP, or clone the repository using Git.
  3. Find the extension folder.
    Extract the ZIP and open the google extension folder containing manifest.json.
  4. Open Chrome Extensions.
    Type chrome://extensions into Chrome's address bar and enable Developer mode.
  5. Load the extension.
    Click Load unpacked and select the extracted google extension folder.
  6. Test the extension.
    Open its popup, try the implemented features and inspect extension errors if anything fails.
